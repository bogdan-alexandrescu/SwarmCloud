# Add a Claude account

Your workspace runs nothing until it has a Claude account to run on. You can add your own, or ask an admin to lend you one from the shared pool.

## Add your own

1. Open [Capacity › LLM Providers › Plans](/capacity/llm-providers/plans), or press **Add key** on the checklist step **Add a Claude account**.
2. Press **Add account**.
3. In **label**, type a short name, for example `laptop` (lowercase letters, digits and dashes).
4. Leave **lend to (optional)** empty to keep the account for yourself.
5. Press **Start the sign-in**, then **Sign in to Claude ↗**. A new tab opens.
6. Sign in to Claude there and copy the code it shows.
7. Paste the code back in the console and press **Add this account**.
   You should see the account in the list, and the checklist step marked done.

## Borrow one instead

1. Open [the setup checklist](/setup).
2. At **Add a Claude account**, press **Request a loan**.
   You should see "Loan requested".
3. An admin lends you an account on [Admin › Platform people](/admin/people) with **Lend…**.
   Accounts lent to you show under **Lent to you** on [Capacity › LLM Providers › Plans](/capacity/llm-providers/plans).
