# Sign in to the console

1. Open the console address your platform team gave you, for example `https://swarm.example.com`.
2. Sign in with your work account.
   You should see **Home**, with the menu on the left (on a phone, under the menu button).
3. Open [Overview](/overview).
   You should see the card **Set up SwarmCloud** with its checklist. The first step, **Sign in**, is done and shows your email.
4. Press **Open setup** on that card, or go to [the setup checklist](/setup), to see every step on one page.

## The setup checklist

These are the steps, in order. Each one says what to press next.

| Step | What it means | Page in this guide |
|---|---|---|
| Sign in | You are signed in. | this page |
| Request your workspace | You have your own workspace. | [Request your workspace](request-workspace.md) |
| Add a Claude account | Your workspace has a Claude account to run on. | [Add a Claude account](claude-account.md) |
| Connect GitHub | SwarmCloud may act as you on GitHub. | [Connect GitHub](connect-github.md) |
| Install the App | The GitHub App is installed where your repositories live. | [Connect GitHub](connect-github.md) |
| Enable orgs | You chose which owners agents may reach. | [Connect GitHub](connect-github.md) |
| Choose repositories | You chose the repositories agents may use. | [Choose repositories](choose-repositories.md) |
| Verify access | Clone, push and pull request were checked. | [Choose repositories](choose-repositories.md) |
| Ready | You can start your first agent. | [Start an agent](submit-work.md) |

## If it does not work

* "Your session expired": press **Reload to sign in**.
* "This account cannot use SwarmCloud": sign in with your work account instead.
* More: [Troubleshooting](troubleshooting.md).
