# What SwarmCloud is

SwarmCloud runs coding agents for you in the cloud, not on your laptop.

1. You describe a change; an **agent** works on it in a copy of your repository.
2. A **workflow** is several agents in order, each step building on the last.
3. The result comes back as a patch or as a pull request on GitHub.
4. Your work runs in your own **workspace**: its own identity, storage and secrets.
5. You drive it from the web **console** or from Claude Code with the **sc plugin**.

## What you need

* A work account that the deployment lets in.
* A GitHub account with access to the repositories you want agents to change.
* About 20 minutes for setup. An admin approves your workspace on the way.
