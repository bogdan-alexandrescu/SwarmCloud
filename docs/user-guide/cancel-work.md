# Stop an agent or cancel a workflow

## In the console

An agent:

1. Open the agent from [Work › Agents](/agents).
2. Press **Stop** and confirm.
   You should see "The request is recorded." The agent stops at its next heartbeat.

A workflow:

1. Open it from [Work › Workflows](/workflows).
2. Press **Stop workflow**. The dialog **Stop this workflow?** asks you to confirm.
3. Press **Stop the workflow**. **Keep it running** closes the dialog and changes nothing.

## In Claude Code

Ask in plain words, for example "cancel workflow wf_…" or "stop that agent". Claude Code says what it will cancel before it does.

You need the **member** role or higher to cancel.
