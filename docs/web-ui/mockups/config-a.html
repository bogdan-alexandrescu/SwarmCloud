Proposal A: Config as a calm settings app

One of five competing proposals for #2157 (CONFIG-MOCKUPS-A to E). BGD picks one; nothing here is built. Every surface the brief names is drawn once, at desktop width (1440) and at phone width (390). The theme toggle above, and the same toggle in each frame's panel foot, switches every frame between light, dark and system. All data is example data: the user is Operator, hosts are swarm.example.com and app.example.com, and no value on this page is a credential.

Idea

Config reads like a settings application. The panel lists the pages. Each page is one column, at most 860px wide, of titled groups: lists and small tables, quiet and dense, with each row's actions at its right edge. Secrets is one page. A scope tab bar (Workspace · Yours · Repository) sits at the top. The Repository scope adds a repository picker and an Agents | GitHub Actions switch, and under them sit the grouped tables (For agents · QA sign-ins · GitHub). Every value is set in a side sheet, the one-time form. Platform counts' Over time is a compact chart over its table. Admin uses the same page grammar, so an admin learns one layout.

Pros

  • One grammar for every page (head, then groups, then rows with actions at the right), so the new pages and the moved ones look like one product.
  • The single column keeps long pages readable and lets them collapse to a phone without a second design. Rows wrap and tables become label and value pairs.
  • A side sheet keeps the page in view while a value is typed, and it is the only place a value is ever entered.
  • Scope tabs make the override order visible: one name, three scopes, and the row says which value wins.

Risks

  • Dense and quiet means little hierarchy. A broken state (an expired token, an "any branch" environment) must earn its place with a mark and a callout, and the frames do that.
  • The Secrets page grows long in the Workspace scope. Groups help, but there is no in-page index.
  • The column leaves the right half of a 1440 screen empty on most pages. That is deliberate (reading width), but a wide Platform counts table may want more.
  • BGD's rule shows Config › People and roles to admins only. Today every member can read roles (workspace-roles.md Q7), so members lose a read they have now.
