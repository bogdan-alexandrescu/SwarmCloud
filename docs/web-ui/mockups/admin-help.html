Alternatives considered: inline edit with preview cards, and one long Help page
Variant 1

Edit in the row, preview on the cards

Recommended

Idea

Keep today's inline editor and make the binding cards above it react while typing: each card shows "before → after" and highlights the profiles whose can-start figure changes. A "Last changed" column says who and when. Setting 0, or cutting by half or more, opens a confirmation that names the effect and asks for the pool name.

Pros

  • The effect is visible before Save, where today it is only visible after.
  • The confirmation is for the drastic cases only; small changes stay one click.
  • Who changed what lives beside the value it explains.

Risks

  • "Last changed" needs admin_changed_by and admin_changed_at served by the API; until then the column reads "not recorded".
  • Typing the pool name is friction an admin will feel every time they pause a pool.
